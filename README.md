A make.fun bounty entry ($2 prize): one loading-screen tip in 200 characters or fewer, for stressed developers and AI coding agents.

**The tip:** "Tip: while this loads, your agent is Googling your error message — and finding your own unanswered question from 2019."

`main.py` (Python 3, standard library only) writes the tip byte-identical to `$MAKEFUN_OUTPUT_DIR/entry.txt` and refuses entries outside the 1–200 character gate.
